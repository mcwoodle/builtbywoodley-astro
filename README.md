# Built by Woodley

A personal portfolio and workshop journal built with Astro, MDX, Tailwind CSS,
and TypeScript. The static build is deployed to Cloudflare Workers.

## Development

Install dependencies and start the development server from the repository root:

```sh
npm install
npm run dev
```

The development server listens on all local interfaces at port `5572` by
default. Override the port with any of the existing supported forms:

```sh
npm run dev -- 6010
npm run dev -- --port 6010
npm run dev -- -p 6010
npm run dev -- --port=6010
```

Other arguments are forwarded to Astro unchanged. For example,
`npm run dev -- 6010 --open` starts on port 6010 and opens the site in a
browser.

The launcher checks that both standalone GTA map artifacts are present before
Astro starts:

- `public/viz/gta-crime-map.html`
- `public/viz/gta-crime-map-lite.html`

During development, exact `GET` and `HEAD` requests for
`/viz/gta-crime-map` and `/viz/gta-crime-map-lite` resolve to those files, just
as Cloudflare's extensionless HTML handling does in production. The wrapper is
available at `/software/gta-map`.

## Regenerating the GTA maps

The map files are generated by
[`gta-urban-analytics`](https://github.com/mcwoodle/gta-urban-analytics) and
checked into this repository. To rebuild both artifacts without relying on a
sibling checkout or a fixed workspace path, run the following from this
repository's root:

```sh
astro_directory="$(pwd)"
gta_map_source="$(mktemp -d)/gta-urban-analytics"
git clone https://github.com/mcwoodle/gta-urban-analytics.git "$gta_map_source"
cd "$gta_map_source"
uv sync
uv run full-pipeline
uv run build-map
mkdir -p "$astro_directory/public/viz"
cp visualize-kepler-map/dist/standalone.html \
  "$astro_directory/public/viz/gta-crime-map.html"
cp visualize-kepler-map/dist/standalone-lite.html \
  "$astro_directory/public/viz/gta-crime-map-lite.html"
```

If an artifact is missing, `npm run dev` exits with the same workflow and uses
the Astro directory discovered from the launcher itself as the copy target.

## Commands

| Command | Action |
| :-- | :-- |
| `npm run dev` | Start the local server at `http://localhost:5572` |
| `npm run test:dev-tooling` | Run tests for the dev launcher and map route shim |
| `npm run build` | Build the production site to `./dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run astro -- --help` | Show the Astro CLI help |
